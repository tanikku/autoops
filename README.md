# AutoOps

A modern AI workflow automation platform.

## Vision

AutoOps allows users to create AI-powered routines that can execute automatically.

The goal is to eliminate repetitive AI work.

## Features

### Current

- Dashboard
- Routine Management
- SQLite + Prisma
- Manual Execution
- Run History
- Scheduling Metadata
- AI Provider Abstraction

### Planned

- Claude API Integration
- Automatic Scheduler
- Multiple AI Providers
- Team Workspaces
- Notifications

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- shadcn/ui
- Prisma
- SQLite

## Development

pnpm install
